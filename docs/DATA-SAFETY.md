# Play Console — Data safety (Project Phoenix)

Short answers for a coaching help-group app (Capacitor/TWA shell + web SPA).

## Ads
- No ads. App does not contain advertising SDKs.

## Data collected
- **Email** — optional; only if the user submits a lead / contact form.
- **Phone** — optional; only if the user submits a lead / contact form (e.g. WhatsApp outreach).
- Not collected automatically on install or browse-only use.
- No account required to view core marketing / orientation content.

## Data sharing / sale
- Data is **not sold**.
- Not shared with third parties for advertising or analytics resale.
- Contact details used only to respond to the user’s request (founder / coaching ops).

## Security
- **Encryption in transit:** yes (HTTPS).
- Data not required for all features — lead form is optional.

## Deletion
- Users can request deletion of submitted contact data by emailing the founder (store listing contact).

## Approximate Play Console mapping
